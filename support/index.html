How do I open an HTML file in DotHTML?

In Telegram, Files, Mail or Safari downloads, tap the HTML file, tap Share, and choose DotHTML. If you don't see it, scroll the row of apps to the end, tap More, and turn DotHTML on. You can also tap + in DotHTML to import from Files or paste HTML, or drag a file onto the app on iPad.

A page looks broken or a chart is missing

Some files load scripts or styles from the internet. Check your connection; the library's Needs Internet filter shows which files depend on it. For details, open the file and choose ••• → Console to see any errors the page reports.

How do I delete files?

Swipe left on a file in list view, or long-press it and choose Delete. To delete several, use ••• → Select Files. Deleting a file also removes any data the page saved.

Does DotHTML upload my files?

No. Everything stays on your device. See the Privacy Policy.
